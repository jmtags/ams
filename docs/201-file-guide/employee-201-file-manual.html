1. What Is A Digital 201 File?

A 201 file is the employee's official HR file. In this system, the physical folder becomes a secure digital folder.

What HR Can Store

  • Resume or CV
  • Employment contract
  • Government IDs and records
  • SSS, PhilHealth, Pag-IBIG, and TIN documents
  • Medical certificates and clearances
  • Training certificates
  • Performance and disciplinary documents

Why It Helps

  • HR files are easier to find.
  • Missing documents are easier to track.
  • Expired documents can be monitored.
  • Employee files are kept in one organized place.
  • Reports show who has complete or incomplete files.
Important: 201 files contain private employee information. Only authorized Admin and HR users should manage these documents.

3. Create The Default Checklist

The default checklist gives HR a starting list of common employee documents.

Click Create Defaults

Use this if categories or required documents are not yet available. The system will add standard HR document folders and checklist items.

What It Creates

Categories such as Personal Documents, Employment Documents, Government Records, Payroll Documents, Training, and Exit Documents.

5. Understand Document Status

Status tells HR what action is needed for each document.

StatusMeaningWhat HR Should Do
Missing The required document has not been uploaded yet. Ask the employee to submit the document or upload it if HR already has a copy.
Submitted The document has been uploaded but not yet confirmed by HR. Open the file, check if it is correct, then mark it Verified if acceptable.
Verified HR has reviewed and accepted the document. No action needed unless the document expires or must be replaced.
Rejected The uploaded document is not acceptable or needs correction. Add remarks so HR knows why it was rejected and request a replacement.
Expired The document expiry date has already passed. Request an updated document from the employee.
For documents with expiry dates, always enter the expiry date during upload. This helps the Reports view show expired and expiring documents.

6. Review, View, Or Delete A Document

HR can review documents from the Uploaded Documents table.

View

Click the View button to open the file. The system creates a temporary secure link so HR can preview or download the document.

Review

Click the Edit or Review button to update the title, category, requirement, status, expiry date, and remarks.

Delete

Click Delete only when the document was uploaded by mistake or must be removed. Deleted files are removed from the employee file.

Recommended Review Habit

  • Open the document first before marking it Verified.
  • Use Remarks when rejecting a document.
  • Enter expiry dates for IDs, clearances, medical certificates, and permits.
  • Do not delete documents unless you are sure they are not needed.

7. Use The Reports View

The Reports view helps HR monitor employee file completion.

What The Report Shows

  • Completion percentage
  • Required document count
  • Submitted document count
  • Verified document count
  • Missing document count
  • Expired document count
  • Expiring soon document count

How HR Can Use It

  • Find employees with incomplete 201 files.
  • Follow up missing required documents.
  • Request updated copies of expired files.
  • Prepare HR compliance summaries for management.
A 100 percent completion means all required checklist items have a submitted or verified document. HR may still review whether each file is complete and acceptable.

8. Good 201 File Practices

These habits keep employee files clean, useful, and safer to manage.

Do This

  • Use clear document titles.
  • Connect uploads to the correct requirement.
  • Mark documents Verified only after checking them.
  • Use expiry dates when applicable.
  • Review the report regularly.

Avoid This

  • Uploading the same document many times.
  • Leaving unclear file names without a proper title.
  • Marking files Verified without opening them.
  • Sharing employee documents outside authorized HR channels.
  • Deleting files without confirming they are not needed.
Privacy reminder: 201 files may contain IDs, government numbers, medical documents, payroll documents, and other sensitive records. Handle them carefully and limit access to authorized HR/Admin users.
